# ASTRA — Astronaut Health Monitoring Prototype

A front-end-only student project built with HTML, CSS and JavaScript. It uses simulated readings and does not connect to real sensors.

## Run it
1. Extract the ZIP.
2. Open the `astronaut-health-monitor` folder in VS Code.
3. Open `index.html` in a browser, or use the VS Code Live Server extension.
4. Keep an internet connection for Google Fonts and the Chart.js CDN graph. The dashboard itself runs locally.

## Features
- Automatic sample readings every 5 seconds (pause/resume available)
- Manual entry for heart rate, SpO₂, temperature and blood pressure
- Configurable demo thresholds in `script.js`
- Warning/critical event log
- Heart-rate trend chart
- Local browser history using localStorage

## Important
This is a demonstration prototype only. All readings are simulated or manually entered. Thresholds are illustrative and are not validated for astronaut medicine, diagnosis, or real flight operations.
